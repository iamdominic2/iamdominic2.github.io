Is the gaining of a tool an advantage or a disadvantage?

Eg. AI
Well, I would argue that, by itself it's an advantage; the introduction of a tool usually, by itself, is an advantage.

Because it's one more option - if you don't like it, don't use it; use the tools that already existed.

But it can have deeper downsides - for instance if one tool destroys the others, like how social media destroys normal life to an extent.

Plus, too many tools can lead to decision fatigue.
