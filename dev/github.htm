How to publish Scratch games on GitHub

1. Either download the .sb3 file or share it on Scratch

2. Go to TurboWarp Packager and either paste in your Project ID or drag-and-drop the .sb3 file

3. Depending on project, you can tick the "Start project automatically instead of showing a big green flag" option, and mess with Runtime Options and Player Options.
If you wish to be most professional, edit your project to allow restarts without pressing the Green Flag, and disable all Player Options except "Start project automatically instead of showing a big green flag", and turn on High Quality Pen

As standalone HTML

4. Choose Plain HTML and download it.

5. Rename it to index.html

As .zip

This is ideal if index.html is over 100MB big.

4. Choose Zip and download it.

5. Extract the contents to a folder.

Continued

6. Create a GitHub repo (if you have not done so already)

7. Upload the index.html file (Standalone HTML) or the Folder (Zip) either through GitHub itself or through the shell.

8. In the same repo, go to Settings -> Pages. Sources: Deploy from a Branch. Branch: main /root. Save.

9. View your project at https://USERNAME.github.io/REPONAME

Optional things you can add

1. Your Scratch Project converted into texts (useful in checking diffs, will be located at /scripts)

2. the .sb3 file is just a .zip file in disguise, so you can unzip it into something like /media and you will see the raw media assets and a project.json file.

3. Of course, the .sb3 file itself, if you want people to see that it really is Scratch. Of course, you can also do the converse.

4. Package it as Windows, MacOS, Linux apps and upload the .zip files to GitHub Releases (right sidebar)

How to do so: Choose from:

Electron Windows application (32-bit)

WKWebView macOS application

Electron Linux application (64-bit)

Now you're quite a pro! Well done!
