10. The crime of no return (Jan 2023)

An experimental JRPG rendered inside a single text list interface. Battle your worst nemeses, manage status effects, laugh at the dialogue that somehow represents modern society, and explore what a fully realized RPG loop built under extreme design constraints is like - using only raw text strings for battles and emojis for overworld graphics!
